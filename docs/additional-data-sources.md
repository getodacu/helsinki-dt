# Additional Helsinki data sources

Documentation checked: **10 October 2026**. Recommendations concern additions to the existing digital twin, not implementation. Benefits and relative effort are architectural judgments. API documentation/catalogues were checked; complete live payloads, rate limits, current coverage and integration performance were not tested.

**Integration inventory updated: 12 October 2026.** The LIDO-TIKU integration below is verified against the current implementation and recorded 11 October fixtures; this update adds no new live-provider availability checks. The shortlist’s original research date remains 10 October 2026.

## Existing coverage

The repository already integrates Helsinki city models/terrain/solar, Nuuka energy, FMI weather observations, HSL transit and routing, rail, AIS ships, road/port webcams, Ryhti building records/permits, building photos, and City of Helsinki LIDO-TIKU traffic measurements for vehicles, cycling and walking. Traffic counters show valid counts within the last 24 hours, with speeds where available; source publication delays and sparse locations limit coverage. Current air-quality coverage is only Mannerheimintie NO₂. Ryhti themes cover building use, heating method, heating energy source and permit status; they do **not** provide the proposed zoning layer below. This inventory was checked separately against the repository by the parent research task.

## Other useful options and access caveats

- **Traffic incidents:** the existing Digitraffic provider has GeoJSON-based Simple JSON endpoints `/api/traffic-message/v2/traffic-announcements` and `/api/traffic-message/v2/roadworks`, with significant disruptions, timing and geometry. This complements city permit polygons; it is not an exhaustive list of minor street obstructions. [Official road API docs](https://www.digitraffic.fi/en/road-traffic/).
- **Heat and greenery:** HSY's CC BY 4.0 URCLIM thermal-comfort/winter-condition results are finished scenario data last updated **14 January 2022**, not live heat. HSY green roofs include built, spontaneous and potential roofs but rely on **2013 imagery**, published 2016. These are planning overlays requiring explicit dataset dates. Helsinki's newer **May 2026** heat model is marked restricted, primarily official use, with possible project/research release; avoid promising it as an open API. [URCLIM](https://www.hsy.fi/en/environmental-information/open-data/avoin-data---sivut/urban-weather-model-results-of-thermal-comfort-and-difficult-traffic-conditions-in-the-helsinki-metropolitan-area/), [green roofs](https://www.hsy.fi/en/environmental-information/open-data/avoin-data---sivut/green-roofs-in-the-helsinki-metropolitan-area/), [2026 heat-model access](https://kartta.hel.fi/paikkatietohakemisto/pth/?id=670).
- **Published street issue reports:** Helsinki Open311 supports public JSON/XML GET without authentication at `https://palautteet.hel.fi/public-api/open311-public-service/v1`. Locations/status are useful; only reviewed feedback is published and the catalogue says under one tenth of feedback was public in 2025. The API's default is the last 90 days or up to 200 responses; avoid promising complete history. Sending feedback requires a key/agreement and is outside this proposal. [Current official API description](https://www.hel.fi/static/avoindata/kanslia/Open311_API_description_011025.pdf), [catalogue](https://hri.fi/data/en_GB/dataset/helsingin-kaupungin-palauterajapinta).
- **Heritage:** Finnish Heritage Agency publishes archaeology, nationally significant built cultural environments (RKY) and some protected-building layers through WMS/WFS and a daily GeoPackage snapshot, CC BY 4.0. Its protected-buildings dataset omits protection under land-use plans and the Building Heritage Protection Act, so absence cannot mean unprotected. [Official data scope/access](https://www.museovirasto.fi/en/services-and-guidelines/data-systems/kulttuuriympaeristoen-tietojaerjestelmae/kulttuuriympaeristoen-paikkatietoaineistot).
- **Energy certificates:** Varke's certificate register could add certified energy classes, but API access requires a data permit, contract and payment; defer it behind open sources. [Official access conditions](https://www.energiatodistusrekisteri.fi/tietojenluovutus-ja-rajapinnat).

## Suggested first slice

For an everyday city view, start with **Allu, city bikes and Service Map**. For urban-analysis work, start with **zoning, noise and coastal flood zones**. Expanding existing FMI air-quality observations is likely the smallest adapter change, but verify pollutant/station availability before choosing scope. These are recommendations, not measured delivery estimates.

HRI and Helsinki's spatial catalogue are discovery routes to owner datasets, not themselves a guarantee of current payload coverage. Several catalogue pages were accessible only via search-indexed official metadata; their live API responses were not exercised. Keep source attribution, observation/release timestamps, scenario labels and missing-data states in any integration.
